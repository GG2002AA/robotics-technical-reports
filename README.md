
This repository contains selected technical reports presenting my work in autonomous robotics, embodied AI, intelligent decision-making, multimodal perception, and learning-based robotic systems.

The reports focus on integrating AI with autonomous robotic systems, with particular emphasis on adaptive autonomy, resource-aware decision-making, multimodal perception, and reliable robot operation.

## Technical Reports

### 1. Multi-Task and Objective Orchestration for Autonomous Mobile Robots

This report presents a multi-task orchestration architecture for autonomous mobile robots operating under changing environmental conditions and operational constraints. The system combines multimodal perception, mission-level decision-making, spatio-temporal memory, and Behavior Tree-based execution to support adaptive task prioritisation and context-aware autonomy.

**Key areas:**  
Autonomous Robotics · Embodied AI · Multimodal Perception · Adaptive Autonomy · Mission-Level Decision-Making · Spatio-Temporal Memory

### 2. Energy-Conscious Autonomous Mobile Robot

This report presents an energy-aware decision-making approach for autonomous mobile robots. The system combines battery-state estimation, navigation information, and learning-based decision-making to determine when a robot should continue its mission or autonomously initiate recharging. The complete mission–docking–recharging–resumption cycle was validated in simulation.

**Key areas:**  
Autonomous Robotics · Robot Learning · Energy-Aware Autonomy · Intelligent Decision-Making · Autonomous Navigation · Long-Term Robot Operation
